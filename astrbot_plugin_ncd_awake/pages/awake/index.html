电脑保持唤醒

让这台机器在 bot 运行时不休眠、不熄屏。

它管什么

  • 阻止 Windows 因空闲进入睡眠/休眠；可选择连屏幕关闭也一起阻止。
  • 用 SetThreadExecutionState 实现，只对 AstrBot 进程生效，不改注册表、不改电源计划。
  • 关掉开关、重载插件或退出 AstrBot，唤醒请求自动撤销。

它管不了什么

  • 手动关机/重启、开始菜单里的睡眠、合盖动作——这些由你或系统策略决定，插件不拦。
  • Windows 更新自动重启、停电、蓝屏。
  • 非 Windows 系统（会显示不支持）。
原理：常驻线程每 30 秒重申一次 ES_CONTINUOUS | ES_SYSTEM_REQUIRED。
