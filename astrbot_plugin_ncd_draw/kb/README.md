# 标签库数据（不进仓库）

`kb/core/` 与 `kb/full/` 是**数据**，体积大（3.4 MB / 16 MB），也不属于本项目的代码，
所以不入库。插件在没有数据时会返回「标签库是空的」，不会报错。

要用的话，把两套库按下面的结构放进来：

```
kb/
├── core/            ← 核心库，默认加载
│   └── 标签库-核心/*.txt      每行：tag ｜ 中文名 ｜ 帖数 ｜ 释义
└── full/            ← 全量库，只有 model 显式 scope="full" 才加载
    └── 标签库/按分类/*.txt
        （tags.csv / tags.jsonl 会被跳过，不用放）
```

数据格式：每行一条标签，`英文标签 ｜ 中文名 ｜ 帖数 ｜ 释义`；
来源是 Danbooru 公开标签数据（285,326 条），请自行确认许可后再分发。

没有数据也能正常用：`draw_kb_search` 会回一句「标签库是空的」，
其余画图功能（`drawing_tools` / `generate_image` / `switch_model`）完全不受影响。
